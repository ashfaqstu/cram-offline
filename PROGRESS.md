## Decisions made from measurement

| Decision | Why |
|---|---|
| ASR model = **tiny**, not base | base RTF 0.915 — no headroom |
| **Whole-utterance** ASR, not chunked | 5 s chunks gave `"Gohhtaka!"` vs a perfect full transcript. Whisper's encoder assumes a 30 s window. |
| LLM **not pinned** to big cores | 6 unpinned threads (10.95) beat 2 pinned big (8.64) |
| No phase-adaptive affinity | GGML fixes pool affinity at creation; it cannot be changed later |
| Speculative prefill **off** | saturated the big cores during capture and starved the UI |
| Demo language **not Bengali** | measured: tiny → `"Keep it to soul."`, base → `"ki kottisu"` |
| Grammar repetition bounded `{0,2}` | unbounded let the 1B model loop to the token cap |
| Model's `done` flag ignored | it set `d=true` on turn 1 after inventing every slot |
